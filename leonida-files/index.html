About Leonida Files

Leonida Files is an independently operated media project focused on Grand Theft Auto VI (GTA VI). It publishes short-form explainers, commentary and, where the necessary permissions are in place, edited gameplay highlights with original context and analysis. Leonida Files is not affiliated with, endorsed by, or sponsored by Rockstar Games or Take-Two Interactive.

About the Leonida Files publishing application

The Leonida Files publishing application is a private tool operated by the channel owner. It helps prepare videos, manage uploads to the owner's YouTube channel, schedule eligible publications, check upload status and review channel analytics. It can also preserve finished production files in the owner's private Google Drive and send delivery notifications to the owner's configured email address and Telegram account. The application is not offered as a public service.

Read the Leonida Files Privacy Policy for information about Google account data and how the application handles it.

This website provides information about the privately operated application. It does not offer public account registration or third-party access.
